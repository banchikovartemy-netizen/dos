# PCOS 0.6 — лёгкая ретро-футуристическая ОС

PCOS — маленькая 32-битная x86/i386 ОС с собственным freestanding-ядром на C + Assembly. Linux под ней нет. Главная цель — очень слабое железо, простой интерфейс и ретро-футуристический ASCII/HUD в духе машинного зрения из sci-fi.

## Русский интерфейс

Начиная с PCOS 0.6 основной интерфейс полностью русифицирован. Встроенный framebuffer-рендерер содержит собственный лёгкий кириллический bitmap-шрифт, поэтому для русского текста не нужны Linux, FreeType или тяжёлые графические библиотеки.

Экран постоянно разделён на две части: слева список приложений, справа — одно активное приложение. Перемещаемых окон и композитора нет.

Приложения: ФАЙЛЫ, ТЕРМИНАЛ, ЗАМЕТКИ, ПЛЕЕР, ФОТО, ВИДЕО, КАЛЬКУЛЯТОР, ИГРЫ, СЕТЬ, СИСТЕМА, НАСТРОЙКИ.

Темы: красная, зелёная, янтарная, ледяная синяя и монохромная.

## Управление

- `↑ / ↓` — переключение приложений.
- `F1..F11` — быстрый переход к приложению.
- `F12` или `Alt+Shift` — переключение русской/английской раскладки.
- В HUD всегда показана текущая раскладка `RU/EN`.

## Видео

PCOS умеет работать через аварийный VGA text и Multiboot framebuffer. В GRUB есть русские профили 800x600, 1024x768, 1280x720, 1920x1080 и 2560x1440. По умолчанию запускается русский графический режим 800x600.

## Файлы

Видимая структура максимально простая:

```text
pc/
├── apps/
├── files/
├── games/
├── music/
├── photos/
├── video/
├── system/
├── config/
└── temp/
```

База загружается из маленького `pcfs.tar`. Изменения в Заметках/Файлах идут в RAM-overlay. Если присутствует отдельный диск с сигнатурой `PCOSDATA`, изменения сохраняются после перезагрузки. PCOS не пишет на случайный чужой диск без своей сигнатуры.

## Терминал

Терминал остаётся Linux-подобным, поэтому привычные названия команд не меняются:

```text
ls cd pwd cat echo touch mkdir rm mv write
mem net ping dhcp play dos legacydos
theme clear reboot shutdown
```

Все подсказки, результаты и сообщения об ошибках самой PCOS выводятся на русском.

## Медиа

- ФОТО: BMP 24-bit с масштабированием.
- ВИДЕО: лёгкий несжатый AVI/DIB для старых CPU.
- ПЛЕЕР: PCM WAV 8-bit mono через Sound Blaster 16 DMA.
- ПЛЕЕР рисует псевдообложку в ASCII/HUD-стиле.
- В initrd уже есть тестовые BMP/WAV/AVI.

## Сеть

Базовая сеть рассчитана на RTL8139: PCI, Ethernet, ARP, IPv4, DHCP и ICMP ping. Приложение СЕТЬ показывает MAC/IP/шлюз/DNS и счётчики приёма/передачи.

## DOS-игры: два режима

### DOS86 — внутри PCOS

`ИГРЫ -> ENTER` запускает программу в песочнице 1 MiB и оставляет PCOS работающей вокруг неё. Реализованы `.COM`, MZ `.EXE`, 8086/80186, BIOS/DOS API, VGA 320x200 Mode 13h, основа Mode X, клавиатура и мост Sound Blaster.

### Legacy DOS — для 386/DOS4GW

Нажми `L` в ИГРАХ или введи `legacydos`. PCOS выходит из protected mode обратно в real mode и через BIOS загружает второй HDD (`DL=81h`). Это путь для тяжёлых DOS-игр вроде DOOM/Duke3D. Для возврата в PCOS нужна перезагрузка. Режим требует BIOS/Legacy/CSM.

## Arch Linux: сборка

```bash
sudo pacman -S --needed base-devel grub xorriso qemu-system-x86
make clean
make check
make iso
make run
```

ISO PCOS 0.6 создаётся как `build/pcos-0.6.iso`.

Legacy DOS:

```bash
make run-legacy DOSIMG=/path/to/bootable-dos-hdd.img
```

Добавить игру в FAT DOS-образ:

```bash
sudo pacman -S mtools
make legacy-add-game DOSIMG=/path/to/dos.img GAME=/path/to/DOOM
```

PCOS не включает коммерческие игры или MS-DOS. Используй свои легально полученные игровые файлы и загрузочный DOS-образ.
